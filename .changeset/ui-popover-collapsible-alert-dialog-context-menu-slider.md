Add `Popover` (with `PopoverTrigger`, `PopoverContent`, `PopoverAnchor`, `PopoverClose`), `Collapsible` (with `CollapsibleTrigger`, `CollapsibleContent`), `AlertDialog` (with `AlertDialogTrigger`, `AlertDialogContent`, `AlertDialogHeader`, `AlertDialogFooter`, `AlertDialogTitle`, `AlertDialogDescription`, `AlertDialogAction` with a `tone="destructive"` option, `AlertDialogCancel`), `ContextMenu` (the `DropdownMenu` item set, plus `tone="destructive"` on `ContextMenuItem`) and `Slider` (one thumb per value, `thumbLabels` for accessible names) to `@tangle-network/ui/primitives`, on Brand tokens. Apps that kept shadcn CLI copies of these five can import them instead.
