`tangle-drift` gates `settings_layout`: settings page files (route or page modules whose path names settings, or files named for their settings) that import nothing from `@tangle-network/agent-app/settings-react` and sit under no settings page that does. A section route nested under a composing layout route is covered; cards, sections and dialogs drawn inside a page are not pages. The shipped baseline records each surface's count from its default branch, so new local settings pages fail a consumer's gate and the count only falls as apps adopt the shared settings layout.
