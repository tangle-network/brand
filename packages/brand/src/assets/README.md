# SOC 2 Type II badge

`soc-2-type-ii.svg` is Tangle's first-party shield and check badge, not an AICPA seal.
The company compliance handoff identifies SOC 2 Type II with A-LIGN; Drew confirmed the audit passed on October 1, 2026.
Link the badge to the [Tangle Trust Center](https://app.vanta.com/tangle.tools/trust/kzhjp5g62vhwoalztadtz).
Copy this SVG unchanged into each app's static assets; this source asset does not require a component or dependency migration.

# Icons

`icons/` is the icon set every Tangle site serves: copy it unchanged into the site root and link it with `iconLinks` from `@tangle-network/brand/social`.
The touch icon is the tangle.tools knot on its #F2F3FF disc colour, opaque edge to edge so iOS can apply its own mask.
